# NV-BOOST — Internationalisation de l'IHM

Traduction complète de l'interface, **une langue = un fichier JSON**, changement
à chaud depuis un sélecteur en bas à droite de la barre de statut.

Langues livrées : **français, anglais, espagnol, portugais, chinois simplifié**.

---

## 2. Comment ça marche

`Translator` expose une `Q_PROPERTY` **notifiée** contenant tout le dictionnaire :

```cpp
Q_PROPERTY(QVariantMap s READ strings NOTIFY languageChanged)
```

Côté QML, on écrit simplement :

```qml
Text { text: i18n.s.srcTitle }
```

Comme le binding *lit* la propriété `s`, il est automatiquement ré-évalué quand
`languageChanged` est émis. **Le changement de langue est donc instantané** :
pas de redémarrage, pas de rechargement du moteur QML, pas de `retranslate()`.

Pour les chaînes à trous :

```qml
text: i18n.fmt(i18n.s.recFramesDone, [backend.recFrames, backend.recFile])
```

Côté C++ :

```cpp
QString s = TR("stClosed");                       // macro = Translator::instance()->t(...)
QString t = Translator::instance()->t("stOpenFail", { path });
```

### Messages de statut

Le `Backend` ne mémorise jamais le texte affiché, seulement `m_statusKey` +
`m_statusArgs`. Conséquence : un message produit en français reste correct après
un passage au mandarin — il est retraduit à l'affichage.

### Choix de la langue au démarrage

1. Langue mémorisée (`QSettings`, clé `ui/language`)
2. Sinon, langue système (`pt_BR` → `pt`, toute variante `zh` → `zh_CN`)
3. Sinon, français

### Clés manquantes

Le dictionnaire anglais est chargé une fois pour toutes et **fusionné en secours**
sous chaque autre langue : une clé oubliée dans une traduction s'affiche en
anglais plutôt que de casser l'IHM. Un `qWarning` signale toute clé introuvable.

## 3. Ajouter une langue

1. Copier `i18n/en.json` en `i18n/<code>.json` et traduire les valeurs
   (ne **jamais** toucher aux clés, ni aux marqueurs `%1`, `%2`…).
2. Déclarer la ressource dans `resources.qrc` :
   ```xml
   <file alias="it.json">i18n/it.json</file>
   ```
3. Ajouter une ligne dans le constructeur de `translator.cpp` :
   ```cpp
   << makeLang("it", "Italiano", "IT")
   ```

Rien d'autre : le sélecteur se peuple tout seul à partir de cette liste.

## 4. Points de vigilance

- **Polices CJK** : les libellés QML utilisent la police système, qui gère le
  chinois sur Windows, macOS et les distributions Linux disposant de
  `Noto Sans CJK`. L'overlay vidéo, lui, force `Monospace` (`main.cpp`) ; si les
  idéogrammes n'apparaissent pas sur une machine Linux minimale, installer
  `fonts-noto-cjk` ou remplacer la famille par une police CJK.
- Les libellés très longs des curseurs (es/pt) sont tronqués avec `…` ; le texte
  intégral s'affiche au survol.
- Les fichiers JSON doivent être en **UTF-8 sans BOM**.
- `Translator` doit rester instancié avant `Backend` dans `main.cpp`.
